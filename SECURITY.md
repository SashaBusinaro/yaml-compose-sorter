# Security Policy

## Supported Versions

We provide security updates for the latest released version of Docker Compose Sorter.

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a potential security issue in this extension, please do **not** open a public issue.

Instead, please report security vulnerabilities privately via GitHub Security Advisories:

- Go to the **Security** tab of the repository.
- Click **Report a vulnerability**.
- Provide a detailed description of the vulnerability, steps to reproduce, and any proof-of-concept code.

Alternatively, contact the maintainer directly via GitHub or email. We will acknowledge receipt of your report within 48 hours and work with you to remediate the issue promptly.
